# SaaS Product Analytics Dashboard

An interactive Power BI dashboard built to analyze SaaS business performance using key business metrics such as Monthly Recurring Revenue (MRR), Churn Rate, Customer Satisfaction, Feature Usage, and Support Analytics. The dashboard enables data-driven decision-making by transforming raw business data into meaningful insights.

---

## Project Objectives

- Monitor Monthly Recurring Revenue (MRR)
- Analyze customer churn patterns
- Track feature adoption and engagement
- Evaluate customer satisfaction
- Analyze support ticket trends
- Compare business performance across countries
- Support strategic business decision-making

---

## Dataset Overview

The dashboard is built using a relational data model consisting of five interconnected datasets:

- Accounts
- Subscriptions
- Churn Events
- Feature Usage
- Support Tickets

---

## Data Model

![Data Model](data-model.png)

The project uses a star-schema inspired relational model to connect customer accounts with subscriptions, feature usage, churn events, and support tickets, enabling comprehensive business analysis.

## Key Performance Indicators (KPIs)

- Total Accounts
- Monthly Recurring Revenue (MRR)
- Active Accounts
- Churn Rate
- Average Revenue Per Account (ARPA)
- Average Customer Satisfaction Score
- Feature Usage
- Escalation Rate

---

## Business Insights

The dashboard helps answer questions such as:

- How is Monthly Recurring Revenue changing over time?
- Which subscription plans have the highest churn?
- Which features are used the most?
- Which countries generate the highest revenue?
- How do support ticket priorities impact customer satisfaction?
- What are the major reasons behind customer churn?
